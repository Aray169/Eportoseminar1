## Cara menayangkan lewat GitHub Pages

1. Buat repositori baru di GitHub, lalu unggah semua file di atas (pertahankan struktur foldernya).
2. Buka **Settings > Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Simpan. Beberapa menit kemudian situs tayang di `https://USERNAME.github.io/NAMA-REPO/`.
